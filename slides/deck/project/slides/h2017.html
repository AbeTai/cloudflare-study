歴史 3　2017

Workers：ネットワークそのものを「プログラムできる」ようにした

何をしたか

  • 2017年9月発表、2018年3月に誰でも使えるように
  • 世界中のデータセンターで、利用者の JavaScript を直接実行
  • VM やコンテナではなく、Chrome と同じ V8 エンジンの軽い仕組み（isolate）を採用。起動が速く、メモリも少ない

なぜ

顧客の要望（独自のキャッシュや振り分けのルールなど）は多様すぎて、決まった機能を増やすだけでは追いつかなかった

なら顧客に自分でコードを書いてもらえばいい。全拠点で動かすには、VM は重すぎた

出典：blog.cloudflare.com「Introducing Cloudflare Workers」（2017年9月29日）

2017年の Workers が、今の AI の話につながる一番大きな転換点です。顧客の要望が多様すぎて機能追加が追いつかないので、ネットワークの上で顧客のコードを動かせるようにしました。何百もの拠点すべてで動かすために、仮想マシンではなく Chrome と同じ V8 エンジンの軽い仕組みを選んでいます。起動が一瞬で、ハンズオンでもデプロイが数秒で終わるのはこのおかげです。
