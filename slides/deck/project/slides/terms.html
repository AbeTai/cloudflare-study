最低限の用語

この 4 語がわかれば、今日の話は追える

DNS　ネットの住所録

「example.com」という名前を、機械が使う住所（IP アドレス）に変換する仕組み

CDN　コピーの配送網

画像やページのコピーを世界中に置き、利用者の近くから返して速くする

エッジ　利用者に近い場所

ネットワークの「端」。遠くの中央サーバーではなく、近くのデータセンターのこと

サーバーレス　サーバー管理不要

コードだけ渡せば、サーバーの用意・更新・増減はすべてクラウド側がやる

専門用語を4つだけ押さえます。DNS は住所録、CDN はコピーの配送網、エッジは利用者に近い場所、サーバーレスはサーバーの面倒を見なくてよい実行方式です。AI に例えると、サーバーレスは「モデルの API を呼ぶだけで GPU の管理はしない」のと同じ感覚です。
