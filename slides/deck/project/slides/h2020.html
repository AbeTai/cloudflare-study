歴史 5　2020

Cloudflare One：会社の VPN を、ネットワーク側で置き換えた

何をしたか

  • 2020年10月に発表。社員・拠点・社内アプリを一つのネットワークでつなぐ
  • 「社内にいれば安全」ではなく、毎回「誰が・どの端末で」を確認する Zero Trust の考え方

なぜ

パンデミックで全員がリモートワークになり、「会社の城と堀」で守るやり方が成り立たなくなった

Web サイトを守るために作ったネットワークを、社員の通信を守ることに転用できた

出典：blog.cloudflare.com「Introducing Cloudflare One」（2020年10月12日）

2020年にはパンデミックで、社員がみんな家から仕事をするようになりました。会社のネットワークの中なら安全、という前提が崩れたので、毎回本人と端末を確認する Zero Trust を提供しました。これも、すでに世界中にあるネットワークを別の用途に使い回した例です。AI 時代には、AI エージェントが社内システムにアクセスするときの安全な入口としても使われ始めています。
