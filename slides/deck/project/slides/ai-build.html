AI を作る側の機能

AI アプリやエージェントを作るための部品

サービス何をするかハンズオン
Workers AICloudflare の GPU で AI モデルを動かす。コードから 1 行で呼べる触る
AI Gatewayどの AI への通信も一か所で記録・キャッシュ・制限する窓口—
Agents SDK・MCPエージェントや MCP サーバーを Workers 上で作るための道具触る
AI Search・Vectorize自分の資料を AI に検索させる（RAG）—
Sandboxesエージェントがコマンドを実行できる、隔離された実行環境—
Browser Runエージェントにブラウザを操作させる（旧 Browser Rendering）—

出典：developers.cloudflare.com、Agents Week 2026 まとめ記事（2026年4月20日・8月10日）

ここからは AI 関連の機能を整理します。まず AI を作る側です。Workers AI がモデルを動かす本体、AI Gateway が通信の窓口、Agents SDK がエージェントや MCP サーバーを作る道具です。自分の資料を検索させる AI Search、エージェントがコマンドを実行できる Sandboxes、ブラウザを操作させる Browser Run もあります。ハンズオンでは Workers AI と MCP を触ります。
