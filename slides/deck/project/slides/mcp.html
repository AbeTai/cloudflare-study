リモート MCP の仕組み

AI が、ネットの向こうのツールを呼び出す

AI クライアント

MCP サーバー
（Workers で動く）

処理・データ

  1. AI が「どんなツールがある？」と聞く（tools/list）
  2. 質問に合うツールを選び、引数を付けて呼ぶ（tools/call）
  3. 結果を受け取り、それを使って答えを書く

右：ハンズオンで作る MCP サーバーのツールを、Cloudflare の AI Playground から呼んだ画面

MCP の流れを確認します。AI クライアントが MCP サーバーに、どんなツールがあるかを聞きます。質問に合うツールを選んで、引数を付けて呼び出します。返ってきた結果を使って、AI が答えを書きます。リモート MCP では、この MCP サーバーがインターネット上にあります。右の画面は、ハンズオンで作るサイコロのツールを AI が呼び出したところです。AI は乱数を正しく作れませんが、ツールを使えば本物のサイコロの結果を返せます。
