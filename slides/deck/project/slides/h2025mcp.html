歴史 7　2025

リモート MCP とエージェント：AI に「手足」を配れる場所になった

何をしたか

  • 2025年3月：インターネット越しに使えるリモート MCP サーバーを、Workers で作って公開できるように
  • ログイン（OAuth）の仕組みもライブラリで用意
  • Agents SDK：会話の記憶や予定実行を持つ AI エージェントを Workers 上で作れる

なぜ

当時の MCP は自分の PC の中でしか動かず、Web やスマホの利用者には届かなかった

ネット越しに公開し、利用者ごとにログインさせる仕組みは、Cloudflare が得意なネットワークとセキュリティそのもの

出典：blog.cloudflare.com「Build and deploy Remote Model Context Protocol (MCP) servers to Cloudflare」（2025年3月25日）

MCP は、AI にツールを使わせるための共通の規格です。2025年初めの時点では、MCP サーバーは基本的に自分の PC の中で動かすもので、ブラウザやスマホの AI からは使えませんでした。Cloudflare は、インターネット越しに使えるリモート MCP サーバーを Workers で作って公開する仕組みと、ログインの仕組みを出しました。今日のハンズオンの最後で、これを実際に作ります。
